title = "Slapshot Playground"
+++

Slapshot playground is an exploratory data analysis built using NHL shot data sourced from [MoneyPuck.com](https://moneypuck.com). It uses this data
to train a machine learning model to determine if a certain NHL goalie can save a shot from a certain position, certain angle, certain speed etc.

You can learn more at the project's [repo](https://github.com/grqphical/slapshot-playground)
